## 核心项目

### 企业 AI 工作台智能体化

- 背景与目标：原工作台依赖多个功能入口，复杂任务需要用户自行拆解；目标是通过自然语言统一入口完成意图理解、任务规划与工具调用。
- 产品与链路：用户输入 -> 意图识别 -> 任务拆解 -> 技能路由 -> 工具执行 -> 结果汇总 -> 用户反馈。
- 数据与指标：演示数据，操作步骤 4 步降至 1 步，任务成功率 81% 提升至 95%，平均响应时间 4.1 秒降至 2.0 秒。
- 我的职责：定义产品形态、任务边界、路由规则和效果指标，推动算法、研发与业务团队完成灰度上线。

### 企业知识库智能问答

- 背景与目标：企业文档分散且搜索结果无法直接回答问题；目标是建立可溯源的 RAG 问答能力。
- 产品与链路：文档解析 -> 分片 -> 混合检索 -> 重排序 -> 模型生成 -> 引用定位 -> 反馈闭环。
- 数据与指标：演示数据，回答准确率 76% 提升至 91%，引用命中率达到 96%，人工查找时间下降 63%。
- 我的职责：负责检索问答体验、标注规范、Golden Set、Badcase 归因和版本验收。

### 跨会话个人记忆

- 背景与目标：助手无法持续理解用户偏好；目标是在隐私可控前提下建立长期记忆。
- 产品与链路：对话与行为 -> 记忆门控 -> 信息提取 -> 分类存储 -> 语义召回 -> 回答应用 -> 更新与遗忘。
- 数据与指标：演示数据，提取准确率 74% 提升至 93%，应用准确率 58% 提升至 89%。
- 我的职责：设计记忆分类、交互控制、评测体系和分期方案，协调模型与客户端落地。

### 多模态内容搜索

- 背景与目标：图片、音视频和文档缺少统一检索；目标是提升多模态资源发现效率。
- 产品与链路：Query -> 实体识别 -> 多模态向量化 -> 多路召回 -> 重排 -> 结果解释。
- 数据与指标：演示数据，Top 10 召回率 68% 提升至 87%，搜索无结果率下降 32%。
- 我的职责：负责场景定义、排序指标、结果形态与 A/B 测试方案。

### 产品需求自动化工作流

- 背景与目标：客研整理、需求流转和评审材料存在重复劳动；目标是以 Agent 编排产品工作流。
- 产品与链路：目标澄清 -> 任务路由 -> 专项 Agent -> 结果质检 -> 文档写入 -> 定时巡检。
- 数据与指标：演示数据，每周节省约 3 小时整理时间，需求字段完整率由 62% 提升至 94%。
- 我的职责：搭建工作流、定义 Agent 边界、验收规则和异常回退机制。
